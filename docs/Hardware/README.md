# 硬件档案总览

本目录记录 `unified_capture` 涉及的设备。设备名称、标识、接口和输出以当前项目的根目录 `README.md`、部署配置和源码为准；`11-摄像头/` 中的资料只作为历史补充。未被这些材料证实的实物型号细节、镜头排列、线缆和接线均不作推断。

## 验证状态约定

- **已在项目中实现**：当前源码或配置直接支持该设备或设备类别。
- **已板端验收**：项目文档记录了实际 RK3588 验收结果；它不表示全部场景或长期稳定性已经验证。
- **历史资料**：只在 `11-摄像头/` 中出现，当前项目资料尚未再次证实。
- **待确认**：需通过实物检查、USB/I2C 枚举、接线检查或现场采集确认。
