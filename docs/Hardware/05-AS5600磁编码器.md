# AS5600 磁编码器

## 验证状态

- **已在项目中实现**：AS5600 驱动和 `EncoderSensor` 通过 I2C 工作；项目常量为地址 `0x36`、12 位原始角度 `0`–`4095`，换算为每 LSB `0.087890625°`。采集间隔为 10 ms（100 Hz）。
- **已观察到的验收证据**：`docs/2026-07-27-hardware-migration-sampling-validation.md` 记载的 RK3588 短时会话中，AS5600 线程在 `STOP` 后完成；该记录没有给出 AS5600 JSONL 的行数、时间间隔或角度准确度统计。

## 项目集成与输出

采集器在启动时打开配置的 I2C 设备并探测 `0x36`；探测失败不会初始化采集。每次采样读取原始角度、换算角度，并检查磁铁状态，写入 session 根目录：

`encoder-<timestamp>.jsonl`

每行 JSONL 的当前字段定义为：

| 字段 | 含义 |
|---|---|
| `ts_us` | 相对采集起点的单调时钟微秒时间戳 |
| `raw_angle` | 原始 12 位角度值，范围 `0`–`4095` |
| `degrees` | 由原始值换算的角度（代码以三位小数写出） |
| `magnet_detected` | 驱动的磁铁检测结果 |

驱动还定义了无磁铁、过弱、正常和过强的磁场强度状态；采集 JSONL 只记录 `magnet_detected`，不记录强度等级、AGC 或 magnitude。

## 边界与待确认

- **待确认**：当前材料未给出实际 I2C 总线设备路径、引脚、供电、磁铁型号／安装位置或机械零位；不得据此推断物理连接或零位标定。
- **待确认**：尚无 AS5600 长时采样率、丢样、磁场状态分布及角度精度的板端验收数据。需要在目标机械与磁铁安装条件下复核。
- `--no-as5600` 可禁用该采集器；是否启用由运行参数决定，JSONL 存在本身不应被假定为每次 session 的必然产物。
