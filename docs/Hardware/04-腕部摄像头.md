# 腕部摄像头：SL／JHHSW

## 验证状态

- **已在项目中实现**：`mango` 以 iProduct 精确匹配左腕 `SL`、右腕 `JHHSW`，并要求 MJPEG 1440×960@30。配置生成的左右腕通道均使用顶部横向 IMU 码带（`ImuOrientation::HORIZONTAL_TOP`）。
- **已板端验收**：`docs/TODO.md` 记录在 RK3588（LubanCat-4）完成双腕场景验证；`SL` 与 `JHHSW` 匹配正确，实测相机 USB 标识为 `1bcf:2d52`，并已确认 IMU 解码和顶部横向码带。3 秒采集记录左腕 550 个、右腕 638 个 IMU 样本。

## 基本信息

| 项目 | 值 |
|---|---|
| 左腕 iProduct | `SL` |
| 右腕 iProduct | `JHHSW` |
| 实测 USB 标识 | `1bcf:2d52` |
| 目标采集参数 | 1440×960@30（MJPEG） |
| IMU 码带 | 顶部横向；已板端验证 |
| 项目输出 | H.265 MKV 与 IMU JSONL；不生成 `.y8` |

## 当前采集与发现行为

项目按可配置的 iProduct 名称分别匹配左右腕；同名、缺失、重复或缺少目标 MJPEG 1440×960@30 时会报告该侧不可用。`allow_missing_devices=true` 时，缺失一侧或两侧可进入降级就绪状态。该发现规则不代表固定的 USB 端口、物理安装方向或左右实物标签，现场变更可调整配置。

mango 采集固定输出 H.265 MKV，并从视频帧异步解码 IMU JSONL；不录制或封装音频，也不生成 `.y8`。
