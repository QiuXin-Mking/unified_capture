# 郭总摄像头：YCTC_SC233HGS

## 验证状态

- **已在项目中实现**：`cherry` 配置固定使用 `5268:1218`、`3200x1200`、H.264、30 fps；项目以同一 sysfs USB device 父路径配对 UVC 视频节点和 CDC ACM 串口节点。
- **已板端验收**：2026-08-03 在 RK3588 完成 30 秒端到端会话；已确认 `/dev/video0`、`/dev/ttyACM0`、共同 USB 父路径、H.264 3200×1200@30，以及有效的 MKV、IMU、MAG、FRAME_META 和视频帧元数据产物。
- **历史资料**：`11-摄像头/03-郭总摄像头信息.MD` 仅记录“5 V 220 mA”。该数值尚未由当前项目资料或实物复核，不能据此推断供电接线或实际功耗。

上述项目集成信息可追溯到根目录 `README.md` 与 `deploy/camera-map.conf.example`；板端验收证据见 `docs/design/cherry-profile-board-validation.md`。本页不根据宽幅分辨率推断物理镜头位置、排列或接线。

## 基本信息

| 项目 | 值 |
|------|-----|
| 型号 | YCTC_SC233HGS |
| USB 标识 | `5268:1218`（项目 `cherry` 配置） |
| 接口 | USB UVC 视频；同一 USB 父设备下配对 CDC ACM 串口传感器流 |
| 设备节点 | 板端验收确认 `/dev/video0` 与 `/dev/ttyACM0`；发现逻辑按同一 USB 父路径配对，不把节点号作为通用部署映射 |
| 传感器 | SC233HGS |
| 当前分辨率 | 3200×1200 |
| 帧率 | 30fps |

## 画面说明

- 项目将该设备作为 `cherry_stereo` 双目模组采集，当前固定配置为 3200×1200@30。
- 本页不以 3840×1080 或 3200×1200 的宽幅分辨率推断物理镜头排列；布局需实物确认。
- 不支持原生 YUYV/NV12 等原始格式，只输出 H.264/HEVC/MJPEG 压缩流，做图像处理需要先解码。

## 可调参数（v4l2 controls）

| 参数 | 范围 | 当前值 | 说明 |
|------|------|--------|------|
| brightness | 0–100 | 50 | 亮度 |
| contrast | 0–100 | 50 | 对比度 |
| saturation | 0–100 | 50 | 饱和度 |
| hue | 0–100 | 50 | 色调 |
| sharpness | 0–255 | 1 | 锐度（当前几乎关闭） |
| white_balance_temperature_auto | bool | 0（关闭） | 自动白平衡 |
| white_balance_temperature | 1500–15000 | 15000 | 手动色温 |
| exposure_auto | 0=Auto / 1=Manual / 3=Aperture | 0（Auto） | 自动曝光 |
| exposure_absolute | 1–333 | 100 | 手动曝光值（auto 模式下 inactive） |
| power_line_frequency | 0=关 / 1=50Hz / 2=60Hz | 0 | 电源频率防闪烁 |

## 常用调整命令

```bash
# 调亮度
v4l2-ctl -d /dev/video0 -c brightness=70

# 手动曝光模式 + 设置曝光值
v4l2-ctl -d /dev/video0 -c exposure_auto=1 -c exposure_absolute=150

# 开启自动白平衡
v4l2-ctl -d /dev/video0 -c white_balance_temperature_auto=1

# 调锐度
v4l2-ctl -d /dev/video0 -c sharpness=50

# 查看当前所有值
v4l2-ctl -d /dev/video0 --all
```
