# 执行记录

本目录保存测试计划、集成过程和执行结果。它们提供事实与证据；由这些事实形成的技术决策保存在 [`../decisions/`](../decisions/)。

## 使用方式

1. 复制 `TEMPLATE.md` 并使用日期文件名。
2. 记录目标、环境、操作、预期与实际结果。
3. 将可独立撤销或替换的选择提取成 ADR。
4. 将完整故障闭环写入 `../bugs/`。
5. 在 record 与 ADR 之间添加双向链接。
6. 执行 `AGENTS.md` 的完成前检查。
